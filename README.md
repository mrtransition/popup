# 时空书签 · 纪元版

一款革命性的 Chrome 书签管理器，提供自然语言搜索、时间线分组、智能推荐、一键保存等功能。

## ✨ 特性

- **自然语言搜索**：支持“上周的AI文章”、“2024年Vue教程”等模糊语义检索
- **时间线视图**：自动按今天/昨天/本周/本月/更早分组，符合记忆规律
- **智能推荐**：基于关键词重叠度，推荐相似书签
- **一键保存**：快捷键 Ctrl+Shift+S 快速收藏当前页面，自动生成摘要和关键词
- **批量管理**：多选书签，批量删除
- **备份/恢复/去重**：完整的数据管理工具
- **深色/浅色主题**：自动跟随系统或手动切换

## 📦 安装

1. 下载此仓库的 `.zip` 文件并解压
2. 打开 Chrome 扩展管理页面 `chrome://extensions/`
3. 开启“开发者模式”
4. 点击“加载已解压的扩展程序”，选择本文件夹
5. 使用快捷键 `Ctrl+Shift+S` 快速保存当前页面

## 🛠️ 开发

- 无后台脚本，所有逻辑在 `popup.html` + `popup.js` 中实现
- 数据存储：书签元数据（标签、备注、摘要）使用 `chrome.storage.local`
